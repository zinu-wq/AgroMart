# 🌱 AgroMart - Farmers Marketplace Web Application

AgroMart is a full-stack web application that connects farmers and customers through a digital marketplace.

## Features

- Farmer product management
- Browse agricultural products
- Add new products
- Delete/update products
- REST API based backend
- Responsive frontend

## Technologies

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js

Database:
- JSON / MongoDB (যেটা ব্যবহার করেছেন)

## Project Structure

AgroMart
│
├── frontend
└── backend

## How to Run

Backend:
npm install
npm start

Frontend:
Open index.html
